# EvoLab · 人工生命进化实验室

一个用 HTML、CSS、原生 JavaScript 和 Canvas 2D 编写的中文交互式进化实验。观察生命体在二维培养皿中觅食、消耗能量、繁殖与死亡，探索资源供给和基因变异如何改变种群。没有后端、数据库、外部 AI API、远程字体或运行时依赖。

## 运行

最简单的方式是直接用现代浏览器打开仓库根目录的 **`index.html`**。页面使用普通脚本，不依赖模块加载、`fetch` 或服务器，因此支持 `file://` 双击打开，也支持断网运行。

也可以使用 **Node.js 20 或更新版本**启动本地静态服务器：

```sh
npm start
```

打开 <http://localhost:8080>。服务器仅监听本机；可用 `PORT=9090 npm start` 更改端口。运行应用、执行核心测试、静态检查和构建均不需要先执行 `npm install`。

```sh
npm test       # 模拟引擎自动化测试
npm run check  # JavaScript 语法、本地资源、HTML ID 和界面引用检查
npm run build  # 检查后将 5 个静态资源复制到 dist/
```

`dist/index.html` 同样可以直接打开，或将整个 `dist/` 目录交给任意静态文件服务器。构建不转译、不压缩、不下载资源。

可选的真实浏览器验证使用 Playwright，只有这项验证需要开发依赖：

```sh
npm install
npx playwright install chromium
npm run test:browser
```

已有 Chromium 时可以跳过浏览器下载，例如：

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

## 操作与参数生效时间

默认实验种子为 `EVOLAB-2026`，包含 **30 个生命体、120 份随机食物**，每模拟秒补充 8 份食物，每个性状的变异概率为 15%。页面打开后以 1 倍速运行。

| 控制项 | 行为 |
| --- | --- |
| 暂停 / 继续 | 暂停模拟时间、移动、能耗、食物生成和繁殖；仍可查看个体和调整控件。 |
| 1× / 2× / 5× | 改变单位真实时间执行的固定模拟步数，所有生物规则保持一致。 |
| 食物生成速度，0–30 个/秒 | 实时修改，从下一模拟步生效；暂停时等待继续。不会删除已有食物。 |
| 基因变异概率，0–100% | 实时修改，只影响之后出生的后代；不会重新修改现存生命体。 |
| 初始种群，1–150 个 | 修改后显示待应用提示，仅重置时生效。引擎自身允许 0–300，便于测试空种群。 |
| 随机种子 | 仅重置时生效；空输入使用默认种子，界面会去除首尾空白。 |
| 重置 / 应用并重新开始 | 使用所有面板当前值重新生成实验；清空统计、曲线与个体选择，并恢复 1 倍速运行。它不是“恢复默认参数”。 |
| 感知范围 | 切换感知圆的显示，仅影响绘图。选中的个体始终显示其感知范围。 |

点击培养皿中的个体可以查看能量、年龄、速度、感知半径、身体半径和世代。将键盘焦点移到培养皿后，用左右方向键切换个体，按 Escape 取消选择。个体死亡后会显示相应提示。种群灭绝后不会自动补充生命体，需要重置重新开始。

上方统计展示当前存活数量及存活个体的平均性状；空种群均值显示为 0。出生和死亡是本次实验累计值，不把初始种群计为出生。“最高世代”记录本次实验曾出现的最高世代，即使该世代已死亡也保留。曲线每模拟秒采样一次，最多保留最近 600 个样本。

## 模拟规则

世界固定为 **1000 × 640 模拟单位**，与屏幕分辨率和窗口尺寸无关。界面用 `px` 表示世界坐标中的长度（不是设备屏幕像素），用 `s` 表示模拟秒。身体大小指半径，速度单位为 `px/s`。

每步推进 `1/30` 模拟秒。生命体在感知圆中寻找最近的可用食物，朝它移动；没有目标时按种子随机数控制方向变化。身体碰到培养皿边缘时反射。生命体中心与食物中心的距离不大于“身体半径 + 食物半径 2.5”时摄食，每步最多吃一份；每份食物只能被吃一次。

| 性状 | 初始范围 | 允许范围 | 生存收益 | 生存代价 |
| --- | --- | --- | --- | --- |
| 移动速度 `v` | 34–54 | 18–90 | 更快到达食物，探索更多区域 | 能耗随速度平方增加 |
| 感知半径 `r` | 65–115 | 35–180 | 能发现更远处的食物 | 能耗随感知半径平方增加 |
| 身体半径 `b` | 4–7.5 | 3–10.5 | 摄食接触范围更大、能量容量更高 | 能耗随身体半径平方增加 |

每个初始生命体的性状分别在初始范围内均匀随机取值，初始年龄为 0、世代为 1、能量为自身容量的 64%。

### 能量模型

每模拟秒能耗为：

```text
C(v, r, b) = 0.35 + 0.0005 × v² + 0.000025 × r² + 0.018 × b²
每步能量支出 = C / 30
能量容量 Emax(b) = 75 + 12 × b
每份食物补充能量 = 26
```

摄食后的能量不会超过自身容量，多余部分不保存。能耗包含基础维持、运动能力、感知和体型的开销；即使正在转向或边缘反射，也使用这一固定代谢模型。年龄先增加、能量先扣除，再判断死亡；该步已耗尽能量或年龄达到 **140 秒**的生命体直接死亡，不能通过同一步进食复活，也不能继续繁殖。

### 遗传与繁殖

繁殖是无性繁殖，需要同时满足：

1. 年龄至少 **12 秒**。
2. 当前能量至少达到自身容量的 **82%**。
3. 距离上一次繁殖至少 **12 秒**。
4. 种群有可用名额。

后代继承亲代的速度、感知半径与身体半径。每个性状独立按当前变异概率决定是否发生变异；触发时在亲代数值的 **±8%** 内均匀变化，再限制到该性状允许范围。因此 15% 是“每个性状”的触发概率，不是“每个新生个体”的总变异概率；边界裁剪也可能使触发后的数值保持不变。

繁殖先扣除 **12 单位**能量作为成本，再将剩余能量的 **45%** 转移给后代，其余由亲代保留。后代能量也受自身容量限制，未转移部分留给亲代；不会凭空产生繁殖能量。后代出生在亲代附近，年龄为 0、世代加 1，并记录亲代 ID。非遗传状态如年龄、能量、历史位置不作为基因继承。

## 可复现与性能边界

- 随机种子经 FNV-1a 字符串哈希初始化 Mulberry32 伪随机序列。模拟不调用 `Math.random()`，不读取真实时钟；渲染不消耗模拟随机数。
- **相同种子、相同初始配置、相同模拟步数，以及在相同模拟步应用的相同参数修改，得到相同结果。** 只记下最终参数不足以复现中途调参的实验。
- 1×、2×、5×只改变步数与真实时间的对应关系，不能改变同一步的规则。不同帧率、暂停时长和窗口大小不会改变给定模拟步的结果。
- 页面进入后台时停止推进，返回前台不补算后台时间。单帧只累计至多 0.25 秒真实时间，避免设备卡顿后的大量追赶；因此速度是目标速率，设备负载较高时真实耗时可能更长。
- 种群上限为 **300**，食物上限为 **600**；食物达到上限后不积累待生成队列。种群满额时暂停繁殖；该步死亡释放的名额在下一步可用。
- 模拟遍历当前种群时将新生个体放在独立队列，遍历结束后统一加入，避免同一步连锁繁殖或无限增长。
- 食物查询使用大小为 80 单位的空间网格，仅搜索感知区域附近网格。统计历史限制为 600 个样本，防止长时间运行无限占用内存。
- Canvas 以设备像素比绘制（上限 2），并对相邻模拟步的位置进行插值，帮助移动保持平滑；插值不影响计算和选择结果。

## 文件结构

```text
index.html                 中文页面结构、控制项与 Canvas
styles.css                 深色实验室主题、响应式布局与交互样式
js/
  simulation.js            纯模拟引擎；浏览器全局 EvoSim / CommonJS 导出
  renderer.js              培养皿与种群曲线绘制，只读取模拟状态
  app.js                   控件绑定、固定步长调度、统计与个体观察
tests/
  simulation.test.js       Node 内置测试，无浏览器或第三方测试依赖
scripts/
  serve.cjs                本地静态服务器
  check.cjs                语法、资源与界面引用检查
  build.cjs                检查并复制静态文件到 dist/
  browser-test.cjs          可选 Playwright 浏览器验证
package.json               开发命令与可选浏览器测试依赖
README.md                  运行方式、模型与局限
```

模拟逻辑不访问 DOM 或 Canvas，可在 Node 中独立运行。`EvoSim` 导出 `Simulation`、`DEFAULT_CONFIG`、`RULES`、`TRAITS`、`energyCost` 与 `maxEnergy`；规则常量和性状边界都可直接检查。

## 当前局限

- 这是用于探索和教学的简化模型，数值没有真实生物学标定，不能作为现实生态预测依据，也不保证任意参数下都能形成稳定种群。
- 没有捕食、个体间物理碰撞、迁移、性别或有性繁殖；不存在神经网络、学习过程或 AI API。
- 食物均匀随机生成，生命体只追踪最近食物；没有地形、记忆、复杂行为或食物类型差异。
- 个体按数组顺序处理。多个个体争夺同一份食物时，先处理且先满足摄食条件者占有资源，存在顺序偏差。
- 基因的选择只通过觅食、代谢、繁殖和死亡间接产生，不会主动以某种“最优基因”为目标；短时统计波动不等于稳定的进化趋势。
- 所有状态仅存在页面内存中，刷新或关闭页面会丢失实验；暂不提供存档、导出或参数修改时间线。历史曲线仅保存最近 600 个样本。
- 同一 JavaScript 引擎中的相同配置可确定性复现；不同浏览器或引擎的浮点三角函数细节可能有微小差异，长期轨迹不保证跨引擎逐位一致。
